# CVR Trainer

A tiny just-for-fun ChilloutVR trainer-style overlay inspired by GTA V mod menus.

Current state:

- `F4` opens or closes the menu.
- While the menu is open, CVR keyboard/mouse/gamepad input is locked so menu keys do not also trigger game controls.
- Move selection: `Numpad 8` / `Numpad 2`, arrow up/down, or `I` / `K`.
- Change folder/spawnable option: `Numpad 4` / `Numpad 6`, arrow left/right, or `J` / `L`.
- Select/activate: `Numpad 5`, `Numpad Enter`, `Enter`, or `U`.
- Back/close page: `Numpad 0`, `Backspace`, `Esc`, or `O`.
- Mouse navigation: hover selects rows, left click activates, and mouse wheel scrolls rows/options.
