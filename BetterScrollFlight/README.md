# BetterScrollFlight

While flying in worlds that have flight enabled, scroll the mouse wheel to adjust your flight speed. Double-click the middle mouse button to reset it back to 1x.

Requires [UI Expansion Kit](https://github.com/knah/CVRMods).

Inspired by [NAK's ScrollFlight](https://github.com/NotAKidoS/NAK_CVR_Mods/blob/main/ScrollFlight/), no code was copied or directly referenced, except as a guide for how to interact with the CVR HUD.

## Usage

Just fly - scrolling up increases speed, scrolling down decreases it. The speed scale persists between sessions.

- **Scroll wheel** - adjust flight speed
- **Double middle-click** - reset speed to 1x

## Settings

Settings are in the main menu under **Mod Settings** (UI Expansion Kit).

| Setting | Default | Description |
|---------|---------|-------------|
| Enabled | On | Enable or disable the mod entirely |
| Show HUD | On | Show the current speed multiplier in the HUD while adjusting |
| Require Modifier Key | Off | Only adjust speed when a modifier key is held |
| Modifier Key | Left Ctrl | Key to hold when modifier is required |
| Scroll Step | 15% | How much each scroll tick changes the speed |
| Max Speed Multiplier | 10x | Upper limit for the speed scale |
| Reset Speed on Exit Flight | Off | Automatically reset speed to 1x when you land |
