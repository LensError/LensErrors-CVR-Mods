# ThirdPersonOptions

Small ChilloutVR desktop camera utility for extra third-person controls.

## Features

- Adds an optional modifier key for the native `Scroll To Toggle 3P` setting.
- Adds Ctrl+T as a third-person toggle while menus are closed.
- Adds middle-click zoom from third person. Middle-click again to restore the previous third-person distance.
- Adds back, left, right, and front-facing third-person camera positions.
- Adds Ctrl+Y to cycle through third-person camera positions.

## Install

1. Install MelonLoader for ChilloutVR.
2. Put `ThirdPersonOptions.dll` in your `ChilloutVR/Mods` folder.

## Settings

Settings are injected into ChilloutVR's native Settings > Controls page next to `Scroll To Toggle 3P`.

Defaults:

- Ctrl+T Toggle: on
- 3P Middle Click Zoom: on
- 3P Camera Position: Back
- 3P Scroll Modifier: Left Shift
